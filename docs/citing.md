# Citing generate-star-grid

If you use generate-star-grid in your research, please cite it as:

**BibTeX:**
\```bibtex
@software{gluck_generate_star_grid,
  author = {Gluck, Naomi},
  title  = {generate-star-grid},
  url    = {https://github.com/ngluck/generate-star-grid},
}
\```

**APA:**
Gluck, N. *generate-star-grid* [Software]. GitHub. https://github.com/ngluck/generate-star-grid
